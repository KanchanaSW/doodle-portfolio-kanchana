# Kanchana Walagambahu

Personal resume site and live showcase for [doodleui-react](https://www.npmjs.com/package/doodleui-react).

https://doodle-portfolio-2.skw-dev.workers.dev/

## Stack

- Next.js 14 (App Router) + TypeScript
- doodleui-react for every control
- Tailwind CSS for layout
- Vercel for deploy

## Local

```bash
npm install
npm run dev
```

## Deploy

```bash
npx vercel
```

Edit copy in `lib/content.ts`. Shuffle uses `SketchSeedProvider` from doodleui-react.
